请输入播放地址后点击播放。


    

        使用方式：

        1. 方式一（RTSP）：在上方输入流名称和 RTSP 地址，点击「添加并播放」，自动添加流并播放，API 返回值显示在下方。

        2. 方式二（直接地址）：在下方播放地址栏直接输入 HLS 或 FLV 地址后点击播放。

        3. HLS 地址示例：http://127.0.0.1:9080/hls/camera01/index.m3u8

        4. FLV 地址示例：http://127.0.0.1:9080/flv/camera01.flv

        5. FLV 延迟更低（1-3 秒），HLS 兼容性更好。

        6. 浏览器默认禁止自动播放有声视频，播放器已默认静音（muted），可手动开启声音。
